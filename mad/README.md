# Personagens MAD

Coleção de personagens no estilo **stick**: cabeça redonda, rosto simples, corpo arredondado e braços e pernas grossos com contorno escuro. Todos seguem o mesmo modelo.

**88 personagens** + 16 expressões (Nina e Rafael) = 104 desenhos.

## Pastas e arquivos

| Caminho | O que é |
|---|---|
| `png/` | Cada personagem em PNG com fundo transparente (720×1040). Use direto no CapCut, Canva, etc. |
| `svg/` | Os mesmos desenhos em vetor (SVG), sem perda de qualidade. |
| `elenco.png`, `estilos.png`, `mais.png`, `extra.png` | Folhas com todos os personagens de cada grupo. |
| `catalogo.json` | Lista de personagens (id, nome, grupo). |
| `gerar.mjs` | Código que desenha tudo: `node mad/gerar.mjs` |
| `exportar-png.cjs` | Gera os PNGs e as folhas: `node mad/exportar-png.cjs` |
